🏋️ Fitness Microservices Application

A scalable **Spring Boot Microservices-based Fitness Application** designed using modern backend architecture principles including API Gateway, Config Server, and secure service communication.

---
 🚀 Tech Stack

* Java
* Spring Boot
* Spring Cloud (Eureka, Config Server, API Gateway)
* OAuth2 / JWT Authentication
* REST APIs
* MySQL
* Maven

---
 🧩 Microservices Architecture

* **API Gateway** – Central entry point for all requests
* **Config Server** – Centralized configuration management
* **User Service** – Handles user data and authentication
* **Activity Service** – Tracks fitness activities
* **AI Service** – Provides smart recommendations

---
 🔐 Security

* OAuth2-based authentication
* Secure API communication between services

---
 ⚙️ How to Run

1. Start Config Server
2. Start Eureka Server (if added)
3. Start API Gateway
4. Start all microservices

---
📌 Features

* Scalable microservices architecture
* Centralized configuration
* Secure authentication
* Modular and maintainable code
